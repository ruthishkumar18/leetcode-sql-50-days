## 🧠 SQL Topics Practiced

- **Filtering and sorting:** `WHERE`, `ORDER BY`, `LIMIT`
- **Joins and relationships:** `INNER JOIN`, `LEFT JOIN`, self-joins
- **Aggregation:** `COUNT()`, `SUM()`, `AVG()`, `GROUP BY`, `HAVING`
- **Subqueries and set logic:** nested queries, `IN`, `EXISTS`
- **Window functions:** `RANK()`, `DENSE_RANK()`, `ROW_NUMBER()`
- **Data cleanup and formatting:** string functions, date filtering, duplicate handling, and regular expressions
