# Day 45: Patients With a Condition

- **LeetCode:** 1527
- **Difficulty:** Easy

## Problem Summary
Return the ID, name, and conditions of patients who have a condition code beginning with `DIAB1`. Condition codes are separated by spaces, so the prefix must begin at the start of the string or immediately after a space.

## Table
- `Patients(patient_id, patient_name, conditions)`
