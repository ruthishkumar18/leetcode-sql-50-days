# Day 50: Find Users With Valid E-Mails

- **LeetCode:** 1517
- **Difficulty:** Easy

## Problem Summary
Return users whose email prefix starts with a letter and contains only letters, digits, underscores, periods, and hyphens. The domain must be exactly lowercase `@leetcode.com`.

## Table
- `Users(user_id, name, mail)`

## Important Note
The match must be case-sensitive so addresses ending in `@leetcode.COM` are rejected.
